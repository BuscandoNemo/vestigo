# Vestigo

![Vestigo stag holding a cup](assets/vestigo-cup.png)

**Move unseen.**

A browser and workspace for separate profiles and connected browsing. Vestigo is currently available only for **alpha testing**.

[Visit the Vestigo page](https://buscandonemo.github.io/vestigo/)

Updates are delivered inside Vestigo to authenticated testers when a release is ready. This repository contains the public page and brand assets only. Application source and installer releases are private.

Report issues through Help in Vestigo. No public installer downloads are provided here.
